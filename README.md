# 춘천 · 정선 2박3일 비교 보드

2026-10-16(금) ~ 10-18(일) 춘천/정선 여행의 1·2·3안을 **지도와 일정으로 비교**하는 로컬 웹앱입니다.
인천 출발 3명 + 이천 출발 1명이 첫날 점심에 합류하고, 그 뒤는 2대·2명씩 동승, 귀가 때 다시 인천 3명 / 이천 1명으로 나뉘는 구조를 반영합니다.
빌드 도구·패키지 설치 없이 정적 파일만으로 동작합니다.

## 실행

```sh
cd trip-itinerary-app
python3 -m http.server 8765 --bind 127.0.0.1
# 브라우저에서 http://127.0.0.1:8765/ 열기
```

`index.html`을 파일로 직접 열어도 동작합니다. 지도 타일(OpenStreetMap)과 Leaflet은 CDN에서 받아오며,
네트워크가 없거나 타일 로드에 실패하면 **자체 SVG 개략도**로 자동 전환되어 경로 비교는 그대로 가능합니다.
우측 상단 "개략도로 보기"로 수동 전환도 됩니다.

## 사용법

- 상단 3개 카드(탭)에서 안을 고르면 일정·지도 경로·관점별 총 운전시간이 함께 바뀝니다. 키보드 ←/→로 이동할 수 있습니다.
- 일정 항목을 누르면 **이전 장소 → 그 항목** 구간이 지도에서 강조되고 예상 운전시간/거리/도착/체류가 표시됩니다.
  - 첫날 **점심 합류** 항목은 인천 차·이천 차 두 갈래를, 마지막 날 **귀가** 항목은 두 귀가선을 함께 보여 줍니다.
- "전체 보기"는 전 구간과 총 운전시간(인천 차 관점 / 이천 차 관점 별도), 날짜별 시간을 보여 줍니다.
- "현실적 대체안" 체크박스를 켜면 해당 날짜 일정이 교체되고 총계·지도가 동기화됩니다.
- 실제 도로 경로는 상세 패널의 Google 지도 / 카카오맵 길찾기 링크로 확인하세요. 지도의 선은 **개략 동선**입니다.
- URL 해시(`#plan=A&v=...&sel=0.3`)에 선택 상태가 저장되어 링크로 공유할 수 있습니다.

## 세 가지 안

| 안 | 요지 | 첫날 점심 합류 |
|---|---|---|
| 1안 (추천) | 인천·이천 각자 정선 직행, 토 가벼운 관광+강원랜드, 일 귀로에 춘천 닭갈비(큰지붕닭갈비 후보) | 정선 아리랑시장 일대 (제안·미확정) |
| 2안 (시트 기준) | 공유 시트 초안: 금 춘천 닭갈비 합류 후 정선, 토 골프/관광/강원랜드, 일 직행 귀가 | 춘천 닭갈비 (가게 미확정) |
| 3안 (이동 최소) | 춘천 생략, 정선 2박 + 골프/강원랜드/단풍. 춘천은 일요일 선택 경유 | 고한·사북 일대 식당 (제안·미확정) |

각 안에 1~2개의 대체안(컨디션/날씨/춘천 경유 여부)이 토글로 붙어 있습니다.

- 그룹 대화 요약: 날짜, 스크린골프, 강원랜드는 **합의**. 춘천 닭갈비는 **희망**(첫날 점심 여부 미확정).
  9/23 "춘천→정선 이동 부담이라 정선 직행 후 귀로에 춘천" 제안에 동의. 숙소는 "하이원 근처" 제안만 있고 예약 없음.
  9/28 늑골 염좌로 골프 1회 + 단풍 제안.
- 공유 시트 초안: 10/16 10시 인천 출발 → 12시 춘천 닭갈비 → 13:30 정선 출발 → 15:30 장보기 → 17시 펜션 → 17:30 스크린골프.
- 출발·합류·귀가 조건: 인천 3명, 이천 1명, 첫날 점심 합류, 이후 2명씩 동승, 귀가는 인천 3명 / 이천 1명.
- 원본 카카오톡 CSV(부모 프로젝트)는 읽기 전용이며 **앱에 원문·닉네임·개인 정보를 넣지 않았습니다.**
- 장소 표기: `합의` / `희망·미확정` / `제안`(이 보드가 새로 제안) / `후보`(이름만 언급) / `기점`.
  제안·후보 장소는 확정 시설이 아니며 영업시간·예약·요금은 확인하지 않았습니다. 큰지붕닭갈비의 지도 위치는 개략입니다.

## 추정 시간의 한계

- 운전 시간·거리는 `js/data.js`의 `LEGS` 표에 있는 **계획용 어림값**(인천·이천 시내 출발 가정, 교통상황 미반영)이며,
  실시간 길찾기 결과가 아닙니다. 표에 없는 구간은 직선거리 × 1.4 / 55 km/h로 어림하고 화면에 "직선거리 기반"으로 표시합니다.
- 합계는 항상 구간 값을 더해서 계산합니다. **인천 차 관점과 이천 차 관점을 따로** 계산하며 두 차의 시간을 합산하지 않습니다.
- 공통 항목의 도착 시각은 늦게 도착하는 차 기준이고, 다음 항목부터 두 차의 시계가 같아집니다.
- 지도의 선은 점과 점을 잇는 개략 동선입니다(도로 아님). 개략도 모드의 해안선·참고 도시도 정밀하지 않습니다.
- 주말·단풍철 교통, 휴게소 혼잡, 강원랜드 입장 절차, 식당 대기 시간은 반영하지 않았습니다.

## 검증

```sh
node scripts/verify.mjs            # 데이터 무결성 + 관점별 일정/합계 계산 출력
python3 -m http.server 8765 --bind 127.0.0.1 &   # 앱 서빙
node scripts/e2e.mjs               # Chrome headless(DevTools Protocol)로 상호작용 검증 + 스크린샷
node scripts/e2e.mjs --offline     # CDN·타일 차단 상태에서 개략도 fallback 검증
```

E2E는 macOS의 `/Applications/Google Chrome.app`을 사용합니다(`CHROME` 환경변수로 경로 지정 가능). 추가 npm 의존성은 없습니다.

