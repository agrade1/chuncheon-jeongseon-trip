# 춘천 · 정선 2박 3일 일정

친구들과 함께 보는 2026년 10월 16–18일 여행 일정입니다.

- 보기: https://agrade1.github.io/chuncheon-jeongseon-trip/
- 편집: 별도로 전달하는 `#edit=...` 링크가 필요합니다. 이 링크를 가진 누구나 일정을 추가·수정·삭제하고 순서를 바꿀 수 있습니다.
- 저장: Supabase `trip_stops` 테이블. 브라우저 저장소를 사용하지 않습니다.
- 지도: 위치를 지정한 일정을 방문 순서대로 번호 핀으로 표시하고 OSRM 도로 경로를 연결합니다. 실시간 교통은 반영하지 않습니다.

## 실행과 확인

```sh
python3 -m http.server 4173 --bind 127.0.0.1
node scripts/verify.mjs
node scripts/backend-smoke.mjs
node scripts/e2e.mjs
```

`backend-smoke.mjs`는 프로젝트 루트의 Git 추적 제외 파일 `.trip-edit-token`을 읽어 임시 일정을 만들고 삭제합니다. 브라우저 검증은 Chrome을 사용하며 캡처는 `e2e-out/`에 저장합니다.

## 데이터와 권한

초기 일정은 사용자가 정한 흐름만 포함합니다. 12시 춘천 합류 외 시각, 식당, 골프장, 숙소, 루지 시설은 미정입니다. 만항재는 선택 후보이며 기본 경로에서 제외됩니다.

`supabase/schema.sql`은 원격 DB에 적용한 스키마와 초기 데이터입니다. 공개 키는 읽기만 허용하고, 쓰기는 Edge Function에서 편집 링크 토큰을 확인합니다. 토큰 원문은 저장소에 포함하지 않습니다. 장소 검색은 Photon 데모 서버를 사용하며 검색 결과를 직접 선택하거나 지도를 눌러 좌표를 지정할 수 있습니다.

지도·검색·경로의 공개 데모 서버는 이용량 제한이나 일시적인 장애가 있을 수 있습니다. 경로 계산이 실패하면 직선 점선으로 표시하고 실제 도로가 아님을 알립니다.
